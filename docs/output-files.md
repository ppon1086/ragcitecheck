# Output files

Common generated files include:

- `validation_summary.json` — summary of input validation
- `report_meta.json` — report configuration metadata
- `pairwise_config_stability.csv` — pairwise stability across runs
- `per_query_stability.csv` — per-query stability summary
- `instability_examples.md` — selected examples of unstable evidence
- `citation_overlap_hist.png` — overlap histogram visualization
